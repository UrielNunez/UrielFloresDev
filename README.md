# Portafolio de Uriel Flores

El portafolio actual se abre desde `index.html` en la raíz del proyecto. Es el diseño que antes estaba en `redesign/`.

## Estructura activa

- `index.html`: página principal, secciones, enlaces y carga inicial.
- `intro.js` y `walker.js`: animación de entrada y LEGO que recorre la página.
- `redesign.js`: navegación, animaciones de scroll y controles de las colecciones.
- `redesign.css`, `collections.css` y `about.css`: estilos del diseño actual.
- `icons/`: iconos y atribuciones de las habilidades.
- `Assets/`: CSS base, imágenes, modelos 3D Draco y CV que utiliza el sitio actual.

La página necesita servirse por HTTP para cargar los módulos y modelos 3D. Three.js, las fuentes y algunas animaciones auxiliares se descargan de servicios externos.

## Respaldo

`respaldo/portafolio-anterior/index.html` conserva la página principal anterior junto con su carpeta `Assets` completa y las páginas auxiliares. `respaldo/INVENTARIO.md` explica los demás materiales archivados. `respaldo/MANIFIESTO.csv` enumera cada archivo respaldado y su función.
