# Skill icons

Local SVG assets, loaded without an external icon service.

- React, TypeScript, Microsoft SQL Server, Linux, AWS and Azure: [Devicon](https://github.com/devicons/devicon), MIT license. Files use each technology's original icon or wordmark.
- Codex and Gemini: [Lobe Icons](https://github.com/lobehub/lobe-icons), MIT license. Codex uses its product icon; Gemini uses its color icon.
