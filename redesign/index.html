My Introduction

I'm a Software Engineer with experience in both web development and immersive technologies. I enjoy building efficient, user-centered applications, from enterprise web systems using PHP, JavaScript, MySQL, HTML, and CSS to VR, AR, and video game experiences developed with Unity.

Throughout my career, I've participated in the entire software development lifecycle, including requirements gathering, UI/UX design, implementation, database design, testing, and deployment. I also have experience teaching software development and interactive technologies at the university level, helping students build a strong foundation in programming and immersive application development.
